# gwas_data

Scripts used to clean and process several antimicrobial resistance (AMR) datasets to use with the GWAS software GHOST (https://github.com/bacpop/GHOST).

Results using the GHOST models are available in:

> Bayesian bacterial GWAS model reveals threshold-dependent genetic changes in antimicrobial resistance phenotypes
>
> Jackie Toussaint, Joel Hellewell, Tommi Mäklin, Samuel T. Horsfield, John A. Lees
>
> _bioRxiv_ 2026.09.24.754083; doi: https://doi.org/10.64898/2026.09.24.754083
